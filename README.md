# Irpan Afrizal — Interactive 3D Portfolio

> A cinematic developer portfolio built with React, TypeScript,
> Three.js, and React Three Fiber.

## ✨ Overview

This project is an interactive 3D portfolio designed to present
my background, technical skills, projects, research, and interests
through a cinematic web experience.

Rather than using a conventional portfolio layout, this project
combines 3D environments, scroll-driven animations, interactive
objects, and futuristic UI elements to create an immersive
digital experience.

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- Three.js
- React Three Fiber
- Drei
- Motion / GSAP
- CSS

## 🎯 Features

- Interactive 3D environment
- Scroll-driven 3D animations
- Cinematic section transitions
- Futuristic UI
- Responsive design
- Project showcase
- Research & thesis showcase
- Life Beyond Code section
- Performance-aware 3D rendering
